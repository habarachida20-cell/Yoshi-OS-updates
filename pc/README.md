# Yoshi OS — application PC finale

Cette application Windows affiche le statut final du projet.

Elle ne télécharge aucune image et ne modifie pas Windows ou une installation existante.

Statut affiché :

- Projet abandonné
- Version non terminée
- Toutes les versions sont archivées/abandonnées
- Nouvelles installations désactivées
- Nouvelles mises à jour désactivées

Le binaire Windows est construit automatiquement par GitHub Actions.
